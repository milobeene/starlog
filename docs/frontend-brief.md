# 로그인 전

## 1. 랜딩 `/`

서비스의 얼굴. **가장 자유로운 화면** — 표시할 데이터가 거의 없다.

- 로고 / 서비스 이름
- 한 줄 소개
- **버튼 영역** — 상태에 따라 둘 중 하나
  - 처음 온 사람: `로그인` `회원가입` `Google로 시작`
  - 이미 로그인한 사람: `{닉네임}으로 계속` `로그아웃`
- 배경 연출 (여기가 메인)

> 버튼 영역이 **살짝 늦게 나타난다.** 로그인 여부를 확인하고 나서 그려지기 때문에,
> 인트로 연출이 그 시간을 덮어주면 자연스럽다.

## 2. 로그인 `/login`

- 이메일 · 비밀번호
- 로그인 버튼
- `Google로 로그인`
- `비밀번호를 잊었어` / `회원가입` 링크
- **에러 문구 자리** (필드 아래 또는 폼 상단)

## 3. 회원가입 `/signup`

- 이메일 · 비밀번호 · 닉네임
- 가입 버튼 + `로그인` 링크
- **가입 직후 화면이 바뀐다** → "메일함 확인해" 안내. 이 상태도 디자인 필요

## 4. 안내성 화면 4개

생김새가 거의 같다. **가운데 카드 하나 + 짧은 문구 + 버튼 1~2개**.
공용 레이아웃 하나로 커버되면 좋겠다.

| 화면 | 내용 |
|---|---|
| **이메일 인증** | 성공 / 실패 두 얼굴. 실패 시 `메일 다시 보내기` |
| **비밀번호 재설정 요청** | 이메일 입력 → "보냈어" 안내로 전환 |
| **새 비밀번호 설정** | 비밀번호 입력 → 완료 안내 |
| **계정 복구** | 탈퇴 대기 중인 계정용. `복구할래` / `로그아웃` |

# 로그인 후

## 5. 대시보드 `/dashboard`

한눈에 보는 요약. **위는 숫자 타일, 아래는 목록·차트.**

- **요약 타일 4개** — 총 게임 수 · 플레이 중 · 완료 · 총 플레이 시간
- **지금 플레이 중** — 게임 이름 몇 개
- **가로 목록 3줄** — 각각 5개 + `더 보기`
  - 최근 플레이한 게임
  - 오래 플레이한 게임
  - 별점 높은 게임
- **차트 영역** — 장르 분포 · 연도별 완료 수 · 월별 지출

> ⚠️ **총 플레이 시간과 월별 지출은 데이터가 없어서 처음엔 0이고 빈 차트다.**
> 빈 상태를 예쁘게 그리든지, 아예 자리를 빼든지 정해야 한다.

## 6. 라이브러리 `/library`

**가장 밀도 높은 화면.** 세 덩어리.

- **툴바** — 검색창 · 정렬 드롭다운(5종) · 뷰 전환
- **사이드바** — 접히는 그룹 5개. 각 항목 옆에 개수
  - 태그 · 장르 · 상태 · 기기 · 플랫폼 계정
- **카드 그리드** + 페이지네이션

**카드 한 장에 들어가는 것**
```
커버 이미지
게임 이름
장르 칩 2~3개
평점        상태 배지
마지막 플레이 — 3회차 · 2026-01-02 ~ 2026-02-11 · Switch
```
- **태그는 카드에 안 넣는다.** 사이드바에서 폴더처럼 묶는 용도다
- **한 번도 안 해본 게임은 마지막 줄이 통째로 빈다.** 그래도 카드가 안 무너져야 한다
- 빈 상태 2종 — "아직 담은 게임이 없어" / "이 조건에 맞는 게임이 없어"

## 7. 게임 상세 `/library/[entryId]`

**긴 세로 스크롤. 섹션이 여러 개.**

- **헤더** — 큰 커버 + 이름 + 상태 배지 + 평점
- **게임 정보** — 개발사 · 배급사 · 출시일 · 장르 · 평균 클리어 시간
  - **일부 값은 내가 직접 고친 값이다** → 원본과 구분되는 표시가 필요
- **내 기록** — 평점 · 플레이 시간 · **메모(글이 길다. 제목·목록이 섞인 문서 형태)**
- **태그 / 장르** — 칩 추가·삭제
- **플레이 회차 목록** — 회차별 카드 또는 행. 추가·수정 버튼
  - 회차 하나에: 몇 회차 · 기간 · 상태 · 기기 · 에뮬레이터 · 계정 · 입력 방식
- **구매 기록 목록** — 같은 구조. 취득 방법 · 가격 · 날짜 · 플랫폼
- **커버 바꾸기 / 항목 삭제**

> ⚠️ **상태(플레이 중·완료 등)를 고르는 드롭다운을 만들면 안 된다.**
> 회차 기록에서 자동으로 정해지는 값이다. 표시만 하고, 바꾸려면 회차를 건드린다.

## 8. 담기 `/add`

- 검색창 (크게)
- 검색 결과 행 목록 — 썸네일 · 이름 · 출시일 · `담기` 버튼
- **로딩 상태가 눈에 띈다.** 외부 검색이라 몇 초 걸린다
- 결과 없을 때 → `직접 등록하기` 유도

## 9. 설정 `/settings`

**섹션 6개를 세로로 쌓은 긴 화면.** 각 섹션은 제목 + 표/폼.

| 섹션 | 내용 |
|---|---|
| 프로필 | 닉네임 · 메모 |
| 플랫폼 계정 | Steam·PSN 같은 계정 목록. 추가·수정·삭제 |
| 보유 기기 | Switch·PS5 같은 기기 목록 |
| 구독 | 서비스명 · 기간 · 요금 · 결제 주기 |
| 태그 · 장르 사전 | 내가 만든 태그/장르 이름 고치기·지우기 |
| 계정 | Google 연결/해제 · **회원 탈퇴** (확인 단계 필요) |

## 10. 관리자 `/admin`

관리자 1명만 쓴다. **예쁠 필요 없고 표만 읽히면 된다.**

- 회원 목록 · 활동 기록(로그 테이블)
- 게임 마스터 정보 수정 / 중복 합치기
- 플랫폼 · 기기 · 에뮬레이터 목록 관리

# 공통으로 필요한 것

## 반복되는 부품

- **버튼** — 기본 / 강조 / 위험(삭제) / 텍스트만
- **입력** — 텍스트 · 숫자 · 날짜 · 드롭다운 · 여러 줄 · 칩 입력
- **상태 배지 6종** ← 색이 필요하다
  `위시리스트` `백로그` `플레이 중` `일시 중단` `중도 포기` `완료`
- **다이얼로그** — 폼용(회차·구매 기록 추가) / 확인용(삭제)
- **테이블** — 설정·관리자에서 반복
- **칩** — 태그·장르
- **커버 이미지** — 세로로 긴 **약 1 : 1.42** 비율. 없을 때 대체 이미지

## 화면마다 세 얼굴

| | |
|---|---|
| **로딩** | 서버가 잠들었다 깨는 구조라 **첫 요청이 몇 초 걸린다.** 스켈레톤이 실제로 보인다 |
| **비었을 때** | 라이브러리 2종, 대시보드 타일 2개는 **처음부터 빈 채로 시작한다** |
| **에러** | 로그인 만료 · 권한 없음 · 외부 검색 실패 |

## 표시 규칙 몇 개

- **평점은 100점 만점**이다. 별 5개로 바꿔 그려도 되고 숫자로 보여줘도 된다 — 디자인이 정한다
- **금액은 통화를 안 합친다.** 원·달러가 따로 나온다. 차트 축도 갈린다
- **날짜는 `2026-01-02` 형태.** 종료일이 없으면 "진행 중"
- 글자는 한국어지만 **게임 제목에 영문이 섞인다.** 폰트가 둘 다 소화해야 한다
