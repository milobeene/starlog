# STARLOG — 디자인 요청서

게임 백로그(하고 싶은·하는 중·끝낸 게임)를 기록하고 되돌아보는 개인용 서비스.
**서비스명: STARLOG**

이 문서는 **무엇이 들어가고 어디에 놓이는지**만 적는다. 색·타이포·여백은 디자인이 정한다.
이번 범위는 **입구 · 대시보드 · 라이브러리** 세 화면.

---

## 공통 — 상단 헤더

로그인한 뒤의 모든 화면에 붙는다. **입구 페이지에는 없다.**

```
STARLOG        Dashboard    Library    Add +              ◯ MiloBeene
[로고]         [-------- 가운데 메뉴 --------]            [-- 우측 --]
```

- **배경 없이 글자만 떠 있다.** 바탕이 그대로 비친다
- **메뉴 라벨은 전부 영문**
- 현재 위치한 메뉴는 구분되어야 한다
- `Add +` 는 게임을 담는 곳. 나머지와 성격이 달라서 `+` 를 달았다
- 우측 프로필 — 누르면 **Profile / Settings / Sign out** 이 열린다
  - 팝오버 하나로 묶든, 작은 버튼 두세 개를 붙여두든 디자인 판단

---

## 1. 입구 페이지 `/`

로그인하지 않은 사람이 처음 만나는 **표지 한 장**. 헤더도 메뉴도 없다.

```
┌────────────────────────────────────────────┐
│                                            │
│                                            │
│    S T A R L O G                           │  ← 화면 폭을 가득 채운다
│    한 줄 소개                                │
│                                            │
│         [ Log in ]   [ Sign up ]           │
│                                            │
└────────────────────────────────────────────┘
```

- **서비스 이름이 주인공이다.** 화면 가로를 꽉 채우는 크기
- 그 아래 한 줄 소개
- 버튼은 **두 개뿐.** 상태에 따라 내용이 바뀐다

| 상태 | 버튼 |
|---|---|
| 로그인 안 한 사람 | `Log in` · `Sign up` |
| 이미 로그인한 사람 | `Continue as MiloBeene` · `Log out` |

- 버튼 영역은 **로그인 여부를 확인한 뒤 나타난다.** 아주 잠깐 비어 있는 순간이 있다
- 그 외에는 아무것도 없다 — 메뉴, 푸터, 링크 전부 없음

## 2. 대시보드 `/dashboard`

로그인 후 첫 화면. **위에서 아래로 네 덩어리.**

### 2-1. 인사말 (맨 위)

```
[ DASHBOARD ]                    ← 현재 페이지 표시
Welcome back, milobeene!         ← 크게
Here's your gaming overview      ← 작게
```

### 2-2. 요약 타일 4개 (가로 한 줄)

| 타일 | 큰 숫자 | 딸린 내용 |
|---|---|---|
| **Total Games** | 총 게임 수 | — |
| **Currently Playing** | 플레이 중인 개수 | **타일 안에 게임 이름이 나열된다.** 넘치면 `…` 으로 자름 |
| **Completed** | 완료한 개수 | — |
| **Total Hours** | 총 플레이 시간 | — |

> 두 번째 타일만 안에 목록이 들어가서 **다른 셋보다 내용이 많다.**
> 네 타일 높이를 맞출지, 이 타일만 크게 갈지는 디자인 판단.

### 2-3. 게임 목록 3줄

각 줄은 **제목 + 게임 5개 + `More →`** 로 이뤄진다. 가로 스크롤이든 세로 나열이든 자유.

```
Recently Played                                    More →
[게임] [게임] [게임] [게임] [게임]

Most Played                                        More →
[게임] [게임] [게임] [게임] [게임]

Top Rated                                          More →
[게임] [게임] [게임] [게임] [게임]
```

- 게임 한 칸에 들어가는 것: **커버 이미지 · 게임 이름** (+ 줄 성격에 맞는 값 하나)
  - Recently Played → 마지막 플레이 날짜
  - Most Played → 플레이 시간
  - Top Rated → 평점
- 커버는 **세로 3:4 비율** (실측 264×352)

### 2-4. 차트 — 월별 지출 (맨 아래)

- 제목 + 꺾은선 하나. **차트는 이거 하나뿐이다**
- ⚠️ **데이터가 비어 있는 상태로 시작한다.** 빈 차트를 어떻게 보여줄지도 함께 필요

## 3. 라이브러리 `/library`

**왼쪽 사이드바 + 오른쪽 메인** 구조. 메인은 **Grid / Folder** 두 뷰로 바뀐다.
카드를 누르면 가는 **상세는 별도 화면**이라 사이드바가 없다 (3-6).

### 3-1. 사이드바 (왼쪽 고정)

접히는 그룹 5개. 각 항목 오른쪽에 **개수**가 붙는다.

```
STATUS            Playing (4)  Completed (39)  Backlog (25) …
TAGS              명작 (12)  운동 (5) …
GENRES            메트로배니아 (5)  액션 (18) …
DEVICES           Nintendo Switch (23)  PC (31) …
ACCOUNTS          본계정 (31)  서브계정 (4) …
```

- 여러 개를 동시에 고를 수 있다 → **선택된 항목 표시**가 필요

### 3-2. 메인 상단 (뷰가 바뀌어도 항상 있음)

```
[ LIBRARY ]                                   ← 현재 페이지 표시
My Collection                                 ← 크게
Management view for statuses, sorting, and quick edits.   ← 작게
```

### 3-3. 툴박스 (제목 바로 아래)

**그리드 뷰와 폴더 뷰에만 있다. 상세 화면에는 없다.**

```
[🔍 Search games...        ]  [ Sort ▾ ]        [ Grid | Folder ]
[ 선택된 필터 칩들 ×  ×  ×                                      ]
```

- 검색 입력
- 정렬 드롭다운 **5종** — Recently Played(기본) · Rating · Release Date · Name · Playtime
- **뷰 전환 — Grid / Folder 두 개. 처음은 Grid**
- 사이드바에서 고른 필터가 **칩으로 표시되고 여기서 해제**할 수 있다

### 3-4. 그리드 뷰 (기본)

```
Showing 20 on this page · 76 total games

[카드] [카드] [카드] [카드] [카드]
[카드] [카드] [카드] [카드] [카드]

              ‹  1  2  3  4  ›            ← 페이지네이션
```

**카드 한 장**

```
┌──────────────┐
│ [Completed]  │  ← 상태 배지, 커버 위
│              │
│   커버 이미지   │  ← 3:4 세로
│              │
├──────────────┤
│ 게임 이름       │
│ [장르] [장르]   │  ← 칩 2~3개
│ ★ 83.0        │
│ 3회차 · 01.02~02.11 · Switch │  ← 마지막 플레이
└──────────────┘
```

- ⚠️ **한 번도 플레이 안 한 게임은 마지막 줄이 통째로 빈다.** 그래도 카드가 안 무너져야 한다
- 평점이 없는 게임도 많다
- **태그는 카드에 안 넣는다.** 사이드바와 폴더 뷰에서만 쓴다

### 3-5. 폴더 뷰

같은 게임들을 **태그로 묶어서** 보여준다. 그리드와 카드 모양은 같다.

```
▾ 명작 (12)
  [카드] [카드] [카드] …

▾ 운동 (5)
  [카드] [카드] …

▾ 태그 없음 (31)
  [카드] [카드] …
```

- 그룹 헤더에 **태그 이름 + 개수**, 접었다 펼 수 있다
- **태그가 하나도 없는 게임들을 담는 그룹**이 맨 아래 필요하다

### 3-6. 상세 뷰 — 카드를 누르면

**별도 화면으로 열린다.** 사이드바와 툴박스는 없다.

```
←  Back to Library                    ← 좌상단. 링크 하나뿐
```

> **화면 자체의 앞으로/뒤로 버튼은 두지 않는다.** 브라우저 뒤로가기가 그 역할을 한다.

**위에서 아래로**

1. **헤더** — 배경에 큰 배너 이미지, 그 위에 커버 · 게임 이름 · 상태 배지 · 평점 · 장르
2. **요약 스탯 한 줄** — 플레이 시간 · 회차 수 · 내 평점 · 출시일
3. **게임 정보** — 개발사 · 배급사 · 출시일 · 장르 · 평균 클리어 시간
   - ⚠️ **일부 값은 사용자가 직접 고친 값이다.** 원본과 구분되는 표시가 필요
4. **내 기록** — 평점 · 플레이 시간 · **메모**
   - 메모는 **글이 길다.** 제목·목록이 섞인 문서 형태라 읽기 좋은 본문 스타일이 필요
5. **태그 / 장르** — 칩. 추가·삭제
6. **플레이 회차 목록** — 회차마다: 몇 회차 · 기간 · 상태 · 기기 · 에뮬레이터 · 계정 · 입력 방식
7. **구매 기록 목록** — 취득 방법 · 가격 · 날짜 · 플랫폼
8. **커버 바꾸기 · 항목 삭제**

> ⚠️ **상태를 고르는 드롭다운을 만들면 안 된다.**
> `Playing` `Completed` 같은 상태는 회차 기록에서 **자동으로 정해진다.** 표시만 한다.

---

## 표시 규칙

- **평점은 100점 만점**, 소수 첫째 자리까지 (`83.0`). 별로 바꿔 그려도 되고 숫자 그대로도 된다
- **날짜는 `2026-01-02` 형태.** 종료일이 없으면 "진행 중"
- **금액은 통화를 안 합친다.** 원·달러가 따로 나온다
- **커버는 3:4 세로 비율.** 대부분 게임에 커버가 있다
- 글자는 한국어지만 **게임 제목에 영문이 섞인다**
- UI 라벨(메뉴·버튼·섹션 제목)은 영문, 데이터는 원래 언어

## 상태 배지 6종 — 색이 필요하다

```
Wishlist   Backlog   Playing   Paused   Dropped   Completed
```

## 화면마다 필요한 세 얼굴

| | |
|---|---|
| **로딩** | 서버가 잠들었다 깨는 구조라 **첫 요청이 몇 초 걸린다.** 스켈레톤이 실제로 보인다 |
| **비었을 때** | 라이브러리 2종("담은 게임 없음" / "조건에 맞는 게임 없음") · **월별 지출 차트** |
| **에러** | 로그인 만료 · 권한 없음 |
